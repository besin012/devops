# 2주차 - 실습 환경과 Git 기초

## 배운 내용

- 서버는 클라이언트의 요청을 받아 응답하는 역할을 한다.
- 베어메탈은 하드웨어에 OS를 설치해 사용하고, 가상 머신은 각각의 OS를 실행한다.
- 컨테이너는 커널을 공유하면서 실행 공간을 나누는 방식이다.
- WSL2는 Windows에서 리눅스를 사용할 수 있게 해준다. 내 컴퓨터는 Mac이라 터미널을 사용한다.

## 기본 명령어

| 명령어 | 용도 |
|---|---|
| `pwd` | 현재 위치 확인 |
| `ls -la` | 숨김 파일까지 목록 확인 |
| `cd ..` | 상위 폴더로 이동 |
| `mkdir test` | 폴더 만들기 |
| `touch text.txt` | 빈 파일 만들기 |
| `cat text.txt` | 파일 내용 보기 |
| `cp`, `mv`, `rm` | 파일 복사, 이동, 삭제 |
| `chmod +x 파일명` | 실행 권한 추가 |

`>`는 내용을 덮어쓰고, `>>`는 기존 내용 뒤에 추가한다.
`rmdir`은 빈 폴더만 지울 수 있다. `rm -rf`는 삭제 전에 경로를 잘 확인해야 한다.

## Git과 GitHub

Git은 파일의 변경 이력을 관리하는 도구이고, GitHub는 저장소를 온라인으로 공유하는 곳이다.

```bash
git status
git add week02/README.md
git commit -m "week02 : README 정리"
git push
```

- `status`: 변경된 파일 확인
- `add`: 다음 커밋에 넣을 변경 선택
- `commit`: 내 컴퓨터에 버전 저장
- `push`: GitHub에 올리기
- `log --oneline`: 커밋 기록 보기
- `diff`: 변경 내용 비교

브랜치는 작업을 나눠서 진행할 때 사용한다.
`git switch -c 브랜치명`으로 만들고, `git switch 브랜치명`으로 이동한다.

## 기억할 점

커밋만 하면 GitHub에는 올라가지 않아서 push까지 해야 한다.
`git init`은 저장소 루트에서 하고, 주차별 폴더마다 다시 하지 않는다.
README.md에는 해당 주차에 배운 내용을 정리한다.
